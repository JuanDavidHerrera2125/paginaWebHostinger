## 📋 Descripción del Proyecto

**ISoft 3D** es una plataforma web para la industria del modelado e impresión 3D. Permite a los usuarios explorar proyectos categorizados, enviar archivos de diseño tridimensional (`.stl`, `.obj`, `.step`) para cotización directa e interactuar a través de un módulo dinámico de testimonios sincronizado en tiempo real.

---

## ✨ Funcionalidades Principales

* 📦 **Galería de Proyectos:** Catálogo interactivo con filtros por categoría.
* 🎥 **Carrusel Multimedia:** Reproducción continua de procesos de fabricación e impresión 3D.
* 📑 **Cotizador Interactivo:** Carga de modelos 3D y selección de materiales técnicos (PLA, PETG, ABS, Resina).
* ⭐ **Sistema de Reseñas en Tiempo Real:** Integrado con Firebase Firestore para publicación instantánea.
* 💬 **Atención Directa:** Botón flotante para contacto rápido vía WhatsApp Business.
